## 已知的环境类失败分类（需求文档 Day 5）

- 工具坐标不准 → 改用 UI 元素定位（`v2/ui.py` 已实现文本/资源 id 定位）
- LLM 规划不合理 → 优化 `planner` prompt（`v2/prompts.py`）
- 记忆未注入 → 检查 `memory.build_prompt` 到各节点的注入点
- App 弹窗 → 加强弹窗检测（`close_popup` + `vision.detect_popup`）
