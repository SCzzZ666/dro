# Dro 电商 AI 助手 (Dro E-commerce AI Assistant)

这是一个基于 DroidRun 的智能电商助手，能够控制 Android 设备自动执行跨平台比价、找同款商品等任务。它通过 Web 界面接收用户指令，利用多模态大模型（如 Qwen-VL, DeepSeek）分析手机屏幕内容并操作 App（淘宝、京东）。

**核心理念：让 AI 像真人一样“逛”淘宝、“刷”京东。**

---

## ✨ 核心特性

### 1. 🧠 高情商导购 (Empathetic Shopping Guide)
*   **懂语气，更懂你**：不再是冷冰冰的指令执行器。当您说“有什么推荐”时，它会扮演参谋角色，主动提供灵感；当您说“买这个”时，它才会迅速执行。
*   **智能反问**：需求模糊时（如“买个杯子”），它会抛出 **选项气泡**（如 `[保温杯]` `[马克杯]`），拒绝无效审问。
*   **上下文记忆**：记住您的历史偏好（如“喜欢红色的”、“预算200以内”），实现多轮对话的意图锁定。

### 2. 🛡️ 本地化隐私保护 (Privacy First)
*   **数据不出域**：核心控制逻辑运行在用户本地设备，通过 ADB 直连手机。
*   **无痕模式**：采用**内存式存储 (In-Memory Storage)**，聊天记录和任务状态仅在运行时存在，重启即销毁，不上传云端，不留本地痕迹。

### 3. 🧩 模块化架构 (Pluggable Architecture)
*   **平台适配器**：支持通过 Prompt 快速接入新电商平台。
*   **动态执行引擎**：后端不硬编码操作逻辑，而是由 LLM 实时生成 Python 代码并在本地沙箱中执行，扩展性极强。

### 4. � 全能购物模式
*   **全网比价**：自动在京东、淘宝之间切换，采集价格、销量，寻找最低价。
*   **最优方案 (跨平台竞技)**：
    *   **京东找标杆**：优先选自营/旗舰店的高分商品。
    *   **淘宝找挑战者**：寻找同款低价竞品。
    *   **口碑一票否决**：好评率低于 95% 直接淘汰，宁贵勿滥。
*   **智能视觉溯源**：上传图片，AI 基于“视觉特征 + 属性验证”寻找全网同款，打通“看图 -> 购物”闭环。

```text
dro/
├── app.py              # FastAPI 后端入口，负责路由分发

└── requirements.txt    # Python 项目依赖列表
```

## 🚀 快速开始

### 1. 环境准备

1.  **Python**: 3.10+
2.  **Node.js**: 18+ (用于运行 DroidRun Portal)
3.  **Android 设备**:
    *   **真机/模拟器**: 开启 **开发者模式** 及 **USB 调试**。
    *   **App 准备**: 提前安装并登录 **淘宝**、**京东**。
4.  **ADB**: 确保终端能执行 `adb` 命令。

### 2. 启动 DroidRun Portal (基座服务)

Dro 依赖 `droidrun-portal` 来驱动手机无障碍服务。

```bash
# 检查设备连接
droidrun devices

# 启动服务
droidrun setup
```

### 3. 安装依赖

在 `dro` 目录下执行：

```bash
pip install -r requirements.txt
```

### 4. 配置 .env

确保根目录下有 `.env` 文件：

```properties
# 阿里云 DashScope Key (支持 Qwen-VL 和 DeepSeek)
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxx

# DeepSeek 模型现已集成至阿里云 DashScope，直接复用上述 API Key，无需单独配置 DEEPSEEK_API_KEY

# ADB 设备序列号 (通过 adb devices 查看)
DEVICE_SERIAL=127.0.0.1:16416
```

### 4. 连接设备 (关键步骤)

在启动服务前，必须确保电脑已通过 ADB 连接到手机或模拟器。

**针对 MuMu 模拟器用户：**
1. 打开模拟器设置 -> 其他 -> 开启“USB调试”。
2. 查看模拟器端口号（通常在“问题诊断”或右上角菜单中）。
3. 在终端执行连接命令：
   ```bash
   # 请将 16416 替换为你的实际端口号
   adb connect 127.0.0.1:16417
   ```
4. 验证连接状态：
   ```bash
   adb devices
   # 看到 device 状态即为成功
   # List of devices attached
   # 127.0.0.1:16417	device
   ```

### 5. 启动 Dro 服务

```bash
# 在 dro 目录下运行
python -m uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

### 6. 开始体验

1.  打开浏览器访问 `http://localhost:8000`。
2.  **配置任务 (左侧侧边栏)**：
    *   **🍬 智慧大脑**：选择您偏好的模型 (Qwen / DeepSeek)。
    *   **✨ 任务类型**：
        *   `全网比价`：关注价格最低。
        *   `找相似款`：关注外观相似。
        *   `最优方案`：综合性价比。
    *   **🖼️ 参考图片**：(可选) 上传图片，让 AI 按图索骥。
3.  **开始对话 (右侧对话框)**：
    *   在输入框告诉 Dro 你的需求，例如：“我想买个降噪耳机”。
    *   **智能引导**：如果不明确，Dro 会给出 **选项气泡**，点击即可快速回复。
4.  **执行任务**：当意图明确后，Dro 会自动接管手机进行操作。
5.  **查看结果**：Web 界面会实时显示进度，并在 `trajectories/` 生成完整报告。

## 常见问题

*   **Q: 为什么生成的链接在手机上打不开？**
    *   A: 我们已针对移动端进行了适配，生成的链接均为 `m.jd.com` 或 `h5.m.taobao.com` 格式，确保能唤起 App。
*   **Q: 任务执行一半卡住了怎么办？**
    *   A: Dro 内置了**异常自愈机制**。如果遇到弹窗或卡顿，它会尝试点击“关闭”或重启 App。如果长时间无响应，请检查手机是否锁屏或断网。
*   **Q: 如何查看历史记录？**
    *   A: 基于隐私保护原则，服务重启后历史记录会被清空。任务运行过程中的截图轨迹保存在 `trajectories/` 目录下，可按需手动清理。
